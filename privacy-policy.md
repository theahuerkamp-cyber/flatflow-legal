## 2. General Information on Data Processing

We only process personal data of our users to the extent necessary to provide a functional app and our content and services. Processing regularly takes place only with the user's consent (Art. 6(1)(a) GDPR) or to fulfill a contract with the user (Art. 6(1)(b) GDPR).

## 3. What Data We Process

When using FlatFlow, we process the following data:

| Data Type | Purpose |
|---|---|
| Email address | Account creation and login |
| Name | Display within the shared household (e.g. task assignment) |
| Password (encrypted) | Login authentication |
| Stress level input | Fair distribution of chores within the household |
| Task and completion status | Core function of the app (task management) |
| Calendar entries | Shared household schedule overview |
| Karma point score | Gamification feature |
| [Profile picture/avatar, if applicable] | Display within the app |

This data is only shared within the respective household (defined via a household access code) with other members of the same household - never with users of other households or third parties outside the app.

## 4. Firebase (Google)

FlatFlow uses services from **Google Firebase** (Google Ireland Limited / Google LLC) to store and manage user data:

- **Firebase Authentication**: to manage login data (email, encrypted password)
- **Cloud Firestore**: to store usage data (see table above)

The database is configured in the **europe-west3 (Frankfurt, Germany)** region.

A Data Processing Agreement (DPA) pursuant to Art. 28 GDPR is in place with Google. Further information on privacy at Google Firebase: https://firebase.google.com/support/privacy

## 5. Purpose of Data Processing

We process the data listed above exclusively to:

- enable registration and login,
- provide the app's core functions (task distribution, calendar, statistics),
- enable communication between members within the same household.

We do not process data for advertising purposes, and we do not share it with third parties beyond the service providers listed above.

## 6. Retention Period

Your data is stored for as long as your account exists. After deleting your account (via the app's settings), your profile and associated data will be deleted, except for transaction and payment data, which will be retained for up to 10 years to comply with statutory tax and commercial record-keeping obligations.
