## 2. Leistungsbeschreibung

FlatFlow ist eine App zur Organisation von Wohngemeinschaften. Sie bietet unter anderem:

- Verwaltung und faire Verteilung von Haushaltsaufgaben basierend auf angegebenem Stresslevel
- Einen gemeinsamen Kalender für WG-Mitglieder
- Eine Statistik-/Ranking-Ansicht (Karma-Punkte)
- Persönliche Profilverwaltung
