## 2. Leistungsbeschreibung

FlatFlow ist eine App zur Organisation von Wohngemeinschaften. Sie bietet unter anderem:

- Verwaltung und faire Verteilung von Aufgaben anhand des selbst angegebenen Stresslevels
- einen gemeinsamen Kalender für die Mitglieder der WG
- eine Statistik- und Ranking-Ansicht (Karma-Punkte)
- ein persönliches Profil
- optionale Erinnerungen auf dem eigenen Gerät

## 3. Registrierung und Nutzerkonto

- Für die Nutzung ist eine Registrierung mit E-Mail-Adresse und Passwort oder mit „Mit Apple anmelden“ nötig.
- Einer WG tritt man mit einem WG-Code bei, den ein bestehendes Mitglied weitergibt. Wer den Code kennt, kann der WG beitreten und ihre Inhalte sehen. Gib den Code deshalb nur an Personen weiter, die dabei sein sollen.
